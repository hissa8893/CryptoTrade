# Pinned runtime + test dependencies. Install with:  pip install -r requirements.txt
#
# Every package below has a prebuilt wheel for macOS Apple Silicon AND Intel, Linux and
# Windows on Python 3.11-3.14 (verified with `pip download --only-binary=:all:`), so the
# installer never needs a compiler.
#
# ccxt is held at 4.5.64 on purpose: 4.5.65+ hard-pin cryptography>=49, and cryptography
# 49+ ships no Intel-Mac wheels. 4.5.64 accepts any cryptography, so every platform gets
# the patched cryptography 50.0.1 except Intel Macs, which get 48.0.1 (newest with an Intel
# wheel). 48.0.1 has 3 advisories (CVE-2026-69247/-69248/-69249) in its X.509 chain
# verifier and PKCS#7 decryption; neither this app nor ccxt calls those APIs (ccxt only
# imports signing primitives, used for private endpoints this app never calls).
